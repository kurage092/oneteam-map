# ワンチーム食事会マップ（P1試作）

月1の食事会「ワンチーム」の行きたい店・行った店を、地図と動物アバターで共有するWebアプリです。

## 今できること（P1）
- 合言葉＋ニックネームで入る（動物アバター12種から重ならないように選ぶ）
- 店をURLで登録（GoogleマップのURLなら店名と位置を自動入力。それ以外は地図で位置を決める）
- 行きたい店：行きたい人のアバターが店の前でそわそわ、ときどき手を挙げる
- 行った店：参加したメンバーが店の前でジャンプしてバンザイ、旗が立つ
- 会社の場所と、電車30分の目安（半径12kmの点線）
- 店の一覧、メンバー一覧（参加回数・行きたい数）

## 2つのモード
- **デモモード**（初期設定）：データはそのブラウザだけに保存。合言葉は `wanteam`。
- **共有モード**：`index.html` の `SUPABASE_URL` と `SUPABASE_ANON_KEY` を入れると、メンバー全員でデータを共有。
  1. supabase.com で無料のプロジェクトを作る
  2. SQL Editor で `schema.sql` を実行
  3. Project Settings → API の URL と anon key を `index.html` に貼る
  4. 最初に開いた人が合言葉を決める

## まだないもの（P2以降）
候補日の○△×、幹事ローテーション、割り勘、LINE共有ボタン、店の自動提案、地図の踏破、思い出アルバム など。
